# Learn and Grow

This repository is being created for learning and development purposes.
It contains small projects and experiments that help explore practical concepts in web development, backend services, containers, and testing.

## Repository Structure

- root folder: contains the main project overview and documentation
- visitor-counter/: a sample full-stack application used to practice building and connecting frontend and backend services
  - backend/: contains the Python backend service and related tests
  - frontend/: contains the frontend app and its UI assets
  - docker-compose.yml: used to run the project services together

## Purpose

The goal of this repository is to support hands-on learning, improve technical skills, and document progress while building real examples.

## Notes

Each subfolder includes its own README with more specific details about that part of the project.
